# EduBot

Assistente virtual da USCS integrado ao Typebot, com interface de chat flutuante em React.

## Tecnologias

- **React + TypeScript** — Interface do chat
- **Typebot** — Motor de fluxo conversacional
- **Netlify Functions** — Proxy seguro para a API
- **ElevenLabs** — Síntese de voz nas respostas

## Início Rápido

```bash
# Instalar dependências
npm install

# Rodar localmente (requer Netlify CLI)
netlify dev
```

## Deploy

Conecte o repositório à Netlify. As configurações de build já estão definidas no `netlify.toml`.

Consulte o [INTEGRATION.md](./INTEGRATION.md) para detalhes completos.
